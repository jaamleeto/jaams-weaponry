# Jaam's Weaponry

A Minecraft Forge 1.20.1 mod that adds a wide variety of unique weapons, each with distinct mechanics and highly customizable options to tailor your combat style.

## Content

- **Weapons** — Daggers, katanas, kamas, scythes, twinblades, buster swords, and many more across multiple material tiers

## Requirements

- Minecraft 1.20.1
- Forge 47.x
- Java 17
